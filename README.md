# 原创机器人展厅

七位原创机器人可在同一静态网页中切换。默认展示夜行向导暮灯 L-08。桌面选择卡分为四张与三张两行，手机为两列。

| 角色 | 外形 | 文件名 |
| --- | --- | --- |
| 暮灯 L-08 | 蜂蜜色琥珀灯笼核心、象牙白黄铜笼架、六片展开弧形灯罩、三条机械支脚 | `robot-l08` |
| 炉心 F-06 | 砖红与铜色圆筒锅炉、炉膛格栅、压力表、短双足、手持扳手 | `robot-f06` |
| 驮云 C-18 | 冰白深蓝淡紫四足机身、长货舱、短导航头、绑带货箱 | `robot-c18` |
| 苔芽 M-12 | 薄荷绿与奶油白、履带底盘、双叶太阳能天线、机械夹爪 | `robot-m12` |
| 铆钉 R-03 | 日落橙与石墨灰、四轮底盘、单眼镜头、夹臂和货架 | `robot-r03` |
| 星巡 S-21 | 珍珠白与深蓝、圆形机身、白紫双侧涵道风扇、双着陆橇 | `robot-s21` |
| 灯塔 N-07 | 象牙白与橙色、双足身体、青蓝双眼、挥手姿势 | `robot` |

网站支持拖动旋转、滚轮或双指缩放、自动旋转、正面／侧面／背面、重置视角、全屏，以及当前角色的 GLB、Blender 和 PNG 下载。切换时保留自动旋转的开关状态并重置视角。系统要求减少动态效果时，默认暂停自动旋转。

## 文件

- `index.html`：页面、样式和交互。
- `assets/<文件名>.glb`：交互模型。
- `assets/<文件名>.blend`：Blender 源文件。
- `assets/<文件名>.png`：模型渲染图、选择卡缩略图及加载封面。
- `assets/model-viewer.min.js`：本地 model-viewer 脚本。
- `assets/studio.hdr`：模型环境光照。

所有资源使用相对路径，不依赖外部字体或 CDN。请同时发布全部模型和静态资源，并保留 `assets` 目录结构。

## 本地预览

在本目录启动静态文件服务器：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。请通过 HTTP 访问，浏览器通过文件协议打开时可能无法加载模型。

## 交互与验证

模型选择按钮的 `data-model` 为 `l08`、`f06`、`c18`、`m12`、`r03`、`s21`、`n07`，当前按钮有 `aria-pressed="true"`。`#stage` 的 `data-current-model` 对应当前角色，`data-load-state` 为 `loading`、`ready` 或 `error`。模型节点始终可通过 `#viewer` 查询，每次切换会替换节点，以隔离旧加载请求没有 URL 的错误事件；读取节点引用时请在切换后重新查询。

当前状态由 `#status` 的读屏通知更新。使用会穿透 Shadow DOM 的自动化工具时，请用 `#stage > #status` 定位页面状态，以避开 model-viewer 内部同名节点。发生错误时可点击 `#retry-model` 重新加载，或直接选择其他角色。重试会为该角色的模型加载地址添加新的 `retry` 参数，以避开加载器缓存的失败请求；以后切回该角色会复用这个地址，下载链接仍指向原始文件。缩略图保持固定布局，图片尚未加载时显示轮廓占位图。

其他稳定选择器：`#rotate`、`#reset`、`#fullscreen`、`[data-view]`、`#download-glb`、`#download-blend`、`#download-png` 和 `#screenshot-link`。

## 发布

将此目录中的文件完整上传到静态托管服务，并将 `index.html` 设为首页。
